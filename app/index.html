Scoring

  • 1 point — Deal moved to Created stage
  • 2 points — Deal moved to Evaluation stage
  • 3 points — Deal moved to Negotiation stage

Deal Size Multipliers

  • 1x multiplier — Deal value $500K – $999K
  • 2x multiplier — Deal value $1M – $1.99M
  • 3x multiplier — Deal value $2M+

Example Calculations

Example 1: A $750K deal moves to Evaluation = 2 pts × 1x = 2 points

Example 2: A $1.5M deal moves to Negotiation = 3 pts × 2x = 6 points

Example 3: A $2.5M deal moves to Created = 1 pt × 3x = 3 points

Eligibility

  • Minimum deal size: $500K
  • Pre-existing deals already in Evaluation stage are eligible if they advance to Negotiation during the contest period
